Judges can clone the repo and run the same planner without secrets. Each adapter speaks the contract of the real API (Linear GraphQL, GitHub REST, Gmail drafts, Slack chat.postMessage). Live mode is run-live against a disposable workspace — a public URL must not hold your inbox token. The scored artifact is not “we called GPT.” It is: bounded writes across three acting apps, an unsent human-review draft, and a grader that fails when Linear returns 200 and the ticket is still Done.
